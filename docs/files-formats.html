Files & formats

Release archive structure, file formats and column descriptions

Files & formats

The final database is generated locally in:

output/VirMarkDB/

For public use, the curated release is distributed as a versioned archive through Zenodo. See the Releases page for download links.

Release archive structure

VirMarkDB_vX.Y.Z/
├── markers/
├── virus_informations/
├── README.md
├── CITATION.cff
├── LICENSE
└── CHANGELOG.md

markers/

Marker files are organised by taxonomic group and marker name:

markers/<group_id>/<marker>/

Each folder contains the retained ORFs for one marker group:

File Description
<marker_group_id>_protein.fasta Protein sequences of the retained ORFs
<marker_group_id>_nucleotide.fasta Nucleotide sequences of the retained ORFs
<marker_group_id>_virus_orf_description.tsv Per-ORF table with HMM hit metrics and virus metadata

Protein FASTA header

>orf_name marker Kingdom;Phylum;Class;Order;Family;Genus;Species

Example:

>AF012825.2_156 atpase Bamfordvirae;Nucleocytoviricota;...;Species_name

Nucleotide FASTA header

Same structure as the protein header. Headers link directly to the corresponding protein sequence.

ORF description table columns

Column Description
orf_name ORF identifier from Prodigal output
virus_id Genome identifier matched to the manifest
group_id Taxonomic group used for the marker group
marker Marker name
copy_rank Rank among hits for the same genome and marker group
evalue HMMER e-value
score HMMER bit score
best_score Best HMMER score for this genome and marker group
score_ratio ORF score / best score
target_length_aa Predicted ORF length in amino acids
best_orf_length Best-ranked ORF length for this genome and marker group
length_ratio ORF length / best ORF length
position_start ORF start coordinate from Prodigal
position_end ORF end coordinate from Prodigal
Species ICTV species name
Virus_names Virus name from the ICTV VMR

The first-ranked ORF is always retained. Additional ORFs are retained only when they pass the score and length ratio thresholds. See Workflow — hit selection for thresholds.

virus_informations/

File Description
virus_compo_taxo.tsv Wide-format table: one row per genome, one column per marker group. ORF names separated by semicolons when multiple copies are retained.
virus_metadata.tsv Genome-level metadata: virus_id, ICTV_ID, Virus_names, abbreviated names, host source, origin source, taxonomy from Kingdom to Species.

Example structure of virus_compo_taxo.tsv:

virus_id | ICTV_ID | Virus_names | atpase_nucleocytoviricota_orf_names | dnapol_nucleocytoviricota_orf_names | ...

Files excluded from public releases

The following files must not be included in public releases:

input/ncbi.creds
temporary files
local logs
large raw external databases
cluster-specific configuration files
