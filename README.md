# VirMarkDB

**VirMarkDB** is a curated reference database providing protein sequences of viral marker genes for *Nucleocytoviricota* within *Bamfordvirae*.

The database is designed for marker detection, marker-based phylogeny, and taxonomic assignment workflows using curated viral marker-gene references.

## Documentation

Full documentation is available here:

[https://est-oup.github.io/VirMarkDB/](https://est-oup.github.io/VirMarkDB/)

The website includes:

- database content and taxonomic scope;
- marker genes and marker-group strategy;
- workflow and software versions;
- file formats and release structure;
- analyses and coverage statistics;
- contribution guidelines;
- citation and limitations.

## Releases
