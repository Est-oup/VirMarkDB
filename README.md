# VirMarkDB

<p align="center">
  <img src="docs/assets/logo_virmark.png" alt="VirMarkDB logo" width="600">
</p>



**VirMarkDB** is a reference database providing protein sequences of viral marker genes for three viral groups: giant viruses (*Nucleocytoviricota*), phages (*Uroviricota*, via `g23`), and RNA viruses (*Orthornavirae*, via `rdrp`).

It is designed for marker detection, marker-based phylogeny, and taxonomic assignment workflows using curated viral marker-gene references.

## Documentation

Full documentation is available at:

**[https://est-oup.github.io/VirMarkDB/](https://est-oup.github.io/VirMarkDB/)**

The website provides information about:

- database content and taxonomic scope;
- marker genes and marker-group strategy;
- workflow and software versions;
- file formats and release structure;
- coverage statistics and analyses;
- contribution guidelines;
- citation, license and known limitations.
